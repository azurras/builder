# Coordination

For an actual authorized handoff, supply repository/path, branch policy, objective, scope, constraints, inspected targets, dependencies, acceptance checks and return format. Code-changing work includes the applicable Before-Edit Brief and coding standard; reuse the plan's brief when current.

The recipient verifies local assumptions and returns commits/PRs, verification results, blockers and actionable warnings. Record ownership, received evidence, decisions and next action in the dated project session file. Same-agent work does not need dispatch/return artifacts. Blocked or parked work stays incomplete; do not close its issue unless cancellation was requested.
