# Closure

For closure-only scope, inspect existing delivery evidence; do not repeat development.

Verify source item, final commit/PR/merge, required CI and applicable deployment, automated checks, runtime report when required, remaining gaps and published dated memory. Block closure when required evidence is missing. Record why any gate does not apply.

Before an authorized external update, record the exact proposed text and evidence in dated memory and publish it. Then perform the update and read back the resulting issue state. Record the actual result and link on its work date, linking an earlier-date proposal when needed, and publish continuity. A failed update is not successful closure. No source issue means closure is not applicable; never create an issue merely to close it.

Return the actual readiness, evidence, external result and unresolved gaps. AGENTS.md governs trusted instructions and authorization.
