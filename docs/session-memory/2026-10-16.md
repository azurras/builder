**Project:** christopherbell-dev

- User asked for a security review of the website, with fixes for anything it found. [Plan](../implementation-plans/2026-10-16-13-45-christopherbell-dev-mark-proxied-cookies-secure.md).
- **Reviewed and found sound at `2528e37`:** the security filter chain and public matchers; JWT and browser-session authentication; role checks on every API controller; the site monitor's SSRF policy (public-only DNS answers, pinned address, HTTPS 443); shared-folder and music serving headers and path containment; redirect targets; inline JSON-LD escaping; rate limits; the production secret guard; live headers; actuator exposure.
